## How I work

**Discover → model → build → evaluate → deploy → measure → hand off**

The repositories here are original clean-room demonstrations using synthetic or public
data. They are designed to make the engineering decisions, uncertainty, limitations,
and operating controls inspectable—not to imitate customer evidence.
